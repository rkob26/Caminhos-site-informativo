# Caminhos — Acessibilidade Urbana

Landing page do aplicativo **Caminhos**, desenvolvido com a proposta de mapear e avaliar a acessibilidade de locais em Jacareí (SP).

O projeto busca contribuir para uma cidade mais acessível e inclusiva, apresentando uma iniciativa que utiliza a tecnologia para facilitar o compartilhamento de informações sobre acessibilidade urbana.

Este repositório contém o **site informativo do Caminhos**, responsável por apresentar a proposta do aplicativo, seus objetivos e suas principais funcionalidades.

## Funcionalidades

- **Apresentação do projeto**: explicação da proposta e dos objetivos do Caminhos.
- **Identidade visual**: utilização da logo e dos elementos visuais do projeto.
- **Layout responsivo**: organização da interface para diferentes tamanhos de tela, conforme implementado no CSS.
- **Navegação pelo site**: acesso às seções informativas por meio do menu.
- **Divulgação das funcionalidades**: apresentação dos recursos do aplicativo relacionados à acessibilidade urbana.
- **Interações da interface**: comportamentos implementados com JavaScript.

## Como executar

### Pré-requisitos

- Navegador atualizado, como Google Chrome, Microsoft Edge ou Mozilla Firefox.
- Git, caso queira clonar o repositório.
- Visual Studio Code, recomendado para editar os arquivos.

### Executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/rkob26/Caminhos-site-informativo.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Caminhos-site-informativo
   ```

3. Abra a pasta no Visual Studio Code.

4. Abra o arquivo `index.html` no navegador.

   Opcionalmente, utilize a extensão **Live Server** no VS Code para visualizar as alterações durante o desenvolvimento.

Não é necessário instalar dependências para executar a versão estática do site.

## Relação com o aplicativo

O site apresenta o aplicativo Caminhos, cuja proposta é mapear e avaliar as condições de acessibilidade de locais em Jacareí (SP).

Entre os recursos apresentados pelo projeto estão:

- Visualização de locais em um mapa.
- Cadastro de novos locais.
- Avaliação da acessibilidade por meio de notas e itens específicos.
- Compartilhamento de informações que podem ajudar outras pessoas a conhecer as condições de acessibilidade dos espaços.

O site informativo e o aplicativo Android são partes distintas do projeto: este repositório documenta a página web, não o código-fonte do aplicativo.

## Desenvolvimento e contribuições

O projeto pode ser atualizado por meio de contribuições ao repositório.

Para propor alterações:

1. Faça um fork do repositório ou combine as mudanças com os responsáveis.
2. Crie uma branch para desenvolver sua alteração.
3. Realize as modificações e teste o site.
4. Registre as alterações em commits com mensagens descritivas.
5. Envie um pull request, quando aplicável.

### Fluxo de trabalho com Git

Para atualizar sua cópia local:

```bash
git pull origin main
```
